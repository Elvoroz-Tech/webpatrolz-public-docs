# Screenshots to add

Drop images in this folder using the filenames below, then update the
"Screenshots" section in the main `README.md` to display them (a commented
example is already there).

Recommended size: 1280–1600px wide, PNG or JPG, light theme (or show both
light/dark if the product supports it). Blur or replace any real user data,
emails, or domains with placeholder/demo data before capturing.
